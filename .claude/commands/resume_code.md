このプロジェクトは「デジタル庁デザインシステムをベースにした自己紹介ページ」です。
HTMLとCSSを学びながら一緒に実装しています。

## プロジェクトの主要ファイル

- `src/index.html` — メインHTML
- `src/style.css` — メインCSS
- `wireframe.html` — 全セクションのレイアウト参照（必ず見ること）
- `color-theme.md` — CSS変数・カラートークン定義
- `typography.md` — フォントサイズ・行高・文字間隔の定義

## 作業方針

- `wireframe.html` を参照してレイアウト・構造を決める
- カラーはすべて `color-theme.md` の CSS変数（`--text-main` など）を使う
- フォントは `typography.md` の対応表に従う（14px未満禁止）
- コードを出力する際は、重要なCSSやHTMLの実装ポイントを解説つきで出す
- コードを書くのではなく、ターミナルに出力して、ユーザーが写経できるようにする

## タスク

まず以下を読んで現在の実装状況を把握してください：
1. `src/index.html`
2. `src/style.css`
3. `CLAUDE.md` の「実装進捗」セクション

その後、次に実装すべきセクションを `wireframe.html` と照らし合わせて提案し、
ユーザーの確認を取ってから実装コードを解説つきでターミナルに出力してください。
