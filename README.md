# self-introduction-soft4

ソフト4向け自己紹介Webページ。GitHub Pages にデプロイしています。

## 概要

- HTML / CSS のみで構成
- `main` ブランチへの push で GitHub Actions が自動デプロイ

## ファイル構成

```
.
├── index.html        # 自己紹介ページ
├── style.css         # スタイルシート
└── .github/
    └── workflows/
        └── deploy.yml  # GitHub Pages 自動デプロイ
```

## 課題条件

- **提出期限**：4/5（日）
- **提出方法**：`出席番号氏名` フォルダにまとめて圧縮して提出
- **注意**：作成にはAIを使わず自分で取り組むこと（学習目的）

### 必須コンテンツ

- 自分の写真
- スキル・資格・開発してきた内容と役割
- 趣味・推し・今凝っていること
- パーソナルな内容（価値観・神戸電子エピソードなど）

### 必須タグ

`img` / `h1` `h2` / `p` / `ul` `li` / `a`
